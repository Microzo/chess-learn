Lisensi komponen yang dipakai Chess Learn

1. Chess Learn (kode aplikasi ini)
   GPL-3.0-or-later. Teks lengkap: GPL-3.0.txt
   Kode sumber: https://github.com/Microzo/chess-learn

2. Stockfish 17.1 (engine catur, dijalankan di browser lewat WebAssembly)
   GPL-3.0. Teks lengkap: GPL-3.0.txt, daftar pembuat: stockfish-AUTHORS.txt
   Stockfish: https://github.com/official-stockfish/Stockfish
   Port WebAssembly (Stockfish.js oleh Nathan Rugg): https://github.com/nmrugg/stockfish.js
   Berkas engine yang disajikan (engine/stockfish-lite.js dan .wasm) adalah build
   "lite single-thread" tanpa modifikasi dari paket npm "stockfish" 17.1.0.

3. chess.js 1.4.0 (aturan catur)
